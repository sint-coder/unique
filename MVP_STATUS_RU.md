# Unique Write — статус проекта

**Обновлено:** 21 октября 2026 года.

Frontend остаётся на React/Vite. Backend переведён на Node.js: Express API находится в `backend/server.js`, команды администрирования и cron-задачи — в `backend/bin` и `backend/cron`. API подключается к существующей схеме MySQL из `backend/schema.sql`; данные БД менять не нужно. Пароли Argon2id совместимы с ранее созданными аккаунтами.

## Основные возможности

- Регистрация, вход/выход, сессии, подтверждение email, сброс пароля и Google OAuth.
- Переписывание текста через Gemini с ограничением по словам, балансом грантов, учётом токенов и стоимости, сохранением истории и очисткой старых текстов.
- Баланс и подписки, Stripe Checkout и webhook-обработка платежей, отмена подписки.
- Аналитика, администраторские метрики и CRUD справочников кампаний.
- SMTP-письма и ежедневный отчёт; скрипты запускаются через npm scripts.

## Локальный запуск

Нужны Node.js 20+, MySQL 8 или MariaDB 10.5+. Скопируйте `backend/.env.example` в `backend/.env`, заполните секреты и базу, установите зависимости командой `npm install`. Затем запустите `npm run api` и `npm run dev` в отдельных терминалах. Подробные команды находятся в README.

## Конфигурация

AI обработка отключается, если нет Gemini API key или цен входных/выходных токенов. Для регистрации и обработки нужны рабочие SMTP и подтверждение email; Stripe и Google OAuth включаются отдельными ключами. В production замените `APP_KEY`, используйте HTTPS и настройте обратный прокси до Node API. Плановые команды: `npm run cron:cleanup` ежечасно, `npm run cron:report` ежедневно.

## Что проверить перед production

- Запустить полный сценарий регистрации/подтверждения, Google OAuth, обработки текста и истечения баланса на staging базе.
- Сверить Stripe webhook и планы с реальными Price ID и ценами; проверить повторную доставку платежных событий.
- Проверить конфигурацию SMTP, Turnstile и обратного прокси, настроить резервное копирование MySQL и мониторинг.
- Проверить административную воронку и метрики на реальных данных. Секреты и `.env` не включать в архивы и Git.

Автоматические тесты в проекте не добавлялись. Backend использует Node.js и npm.
